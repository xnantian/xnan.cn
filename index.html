07 FAQ

开始之前，
先把关键问题
说清楚

企业还没有整理知识库，可以做 Agent 吗？＋

可以。知识梳理本身就是交付的一部分。我们会先评估现有文档、系统数据和业务人员经验，再确定治理与更新机制。

能否接入现有 CRM、ERP 或内部系统？＋

可以。具备稳定接口的系统通常都能接入；没有标准 API 的旧系统，则需要评估数据库、自动化工具或中间服务方案。

如何避免 Agent 产生错误答案或误操作？＋

通过知识引用、权限隔离、规则校验、工具白名单、关键动作审批和人工接管共同控制风险，并持续监控质量。

项目适合从多大范围开始？＋

建议从业务量稳定、规则清晰、结果可衡量的单一场景切入。完成原型验证后，再决定是否扩展到更多部门与系统。
